# Physical Play — Assisted Yard

A public browser experiment by Dan Gal: one existing physical human with
gameplay assistance, light-prop grips, physical falls, and a stand-up shortcut.

Play in landscape. Drag left to move and right to look. The buttons grip/drop,
jump, flop, stand up and reset. On desktop: WASD, mouse look, Q/E, Space, T, G, R.

This repository contains the static Godot 4.6.1 single-thread web export and
required credits/licenses. It does not contain robot checkpoints, training
tools, local project history, credentials, or workstation documents.

The game runs entirely in the browser. Actual iPhone Safari performance remains
unverified. Engine and adapted asset attribution is available in `credits.html`.
Original game code has no newly granted general-purpose open-source license;
the explicitly identified third-party and adapted assets retain their licenses.

GitHub Pages publishes the root of `main`; `.nojekyll` preserves the static
export. All engine/game asset paths are relative for a project Pages URL.
