Physical Play — Assisted Yard

A small physical-character experiment by Dan Gal. Return to the game.

Character and anatomy assets

The visible human surface, anatomical skeleton and derived rig are based on Z-Anatomy by Lluis V and contributors, also distributed through Models of human anatomy. These adapted assets are distributed under Creative Commons Attribution-ShareAlike 4.0 International.

Z-Anatomy incorporates BodyParts3D, copyright The Database Center for Life Science, released under Creative Commons Attribution-ShareAlike 2.1 Japan. These original attribution and license notices are preserved.

Changes include a fifteen-bone skin mapping, clothing fitted to the anatomy, covered-surface removal, shoulder/hand/knee weight corrections, closed limb seams, and trouser weight repairs. The derived anatomy and fitted clothing retain CC BY-SA 4.0. This asset license does not apply to the game's original code.

The internal legacy reference human mesh uses MakeHuman/MPFB community base assets, supplied under CC0 1.0 Universal. The simple yard, blocks, interface and locally generated accessory geometry are original project work.

Recorded movement reference

A converted face-down get-up reference from DeepMimic, copyright 2018 Xue Bin Peng, is retained as part of the underlying controller. Full MIT license. The experiment's stand-up shortcut uses a fresh character instance rather than claiming to reproduce that motion.

Engine and third-party software

Built with Godot Engine 4.6.1, GDScript, Compatibility/WebGL2 rendering and built-in Jolt physics. The web runtime is the official single-thread release template.

Godot MIT license · Engine third-party copyrights and licenses, including Jolt.

Testing boundary

This is an experiment. Touch controls were exercised in desktop Chromium; actual iPhone Safari performance has not been verified. No account, analytics or server-side game state is required.
